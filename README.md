# PentiaChat

Firebase chat-app til Pentia Mobiles udviklingsopgave. React Native (uden Expo) + TypeScript.

Status

- ✅ Splash screen med routing baseret på login-tilstand
- ✅ Login med Google og Facebook (fejldialog ved fejl)
- ✅ Liste over chatrum, sorteret efter nyeste besked, pull-to-refresh
- ✅ Chatrum: seneste 50 beskeder, realtime opdateringer, scroll op for ældre, send
- ⛔ Push-notifikationer — ikke implementeret
- ⛔ Billed-upload — ikke implementeret

## Kør appen

```sh
npm install
npm start          # Metro
npm run android    # i en anden terminal Enten brug telfeon vis USB eller emulator.
